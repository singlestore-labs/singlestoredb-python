singlestoredb.management.cluster.ClusterManager¶

class singlestoredb.management.cluster.ClusterManager(access_token: str | None = None, version: str | None = None, base_url: str | None = None, *, organization_id: str | None = None)¶

SingleStoreDB cluster manager.

This class should be instantiated using singlestoredb.manage_clusters().

Parameters:

  • access_token (str, optional) – The API key or other access token for the cluster management API

  • version (str, optional) – Version of the API to use

  • base_url (str, optional) – Base URL of the cluster management API

See also
